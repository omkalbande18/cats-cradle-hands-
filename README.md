# 🖐️ Cat's Cradle // Neural Strings

A real-time, browser-based hand-tracking art experience built with MediaPipe and JavaScript.
Bring both hands into frame and watch glowing laser strings connect your fingertips.

## ✨ Features

- 🎥 Live webcam hand tracking (no install, runs in browser)
- 🤲 Detects both hands simultaneously
- 🌈 Neon strings connect each fingertip pair — cyan, magenta, yellow
- 💥 Particle explosions when fingertips touch
- 🖥️ Futuristic UI with CRT scanlines, vignette, and glowing skeleton

## 🚀 Try it Live

👉 [Open the app](https://YOUR-USERNAME.github.io/cats-cradle-hands/)

## 🛠️ How it Works

Built with:
- [MediaPipe Hands](https://mediapipe.dev/) — real-time hand landmark detection
- Vanilla JavaScript Canvas API — rendering, glow effects, particles
- p5.js — animation loop support

## 📸 How to Use

1. Open the link above in **Chrome**
2. Click **Allow** when asked for camera access
3. Hold both hands up in front of your webcam
4. Move them apart and together to stretch the strings
5. Touch fingertips to trigger **particle explosions** 💥
